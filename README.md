# 🩺 Online Healthcare & Consultation Platform

A comprehensive web application designed to streamline patient-doctor interactions, appointment scheduling, digital prescription management, and lab test bookings. Built using modern backend and database practices to support multi-service healthcare workflows.

---

## 🌟 Key Features

*   **Doctor Appointment Scheduling:** Dynamic booking system handling real-time doctor availability and schedule management.
*   **Digital Prescription Management:** Secure creation, storage, and retrieval of patient prescriptions for seamless access.
*   **Lab Test Bookings:** Integrated module for searching, selecting, and scheduling diagnostic lab services.
*   **Medical Records Management:** Structured database handling patient histories and service logs safely and efficiently.
*   **Role-Based Workflows:** Tailored interfaces and access points for patients, healthcare providers, and administrators.

---

## 🛠️ Tech Stack

*   **Frontend:** JavaScript (ES6+), HTML5, CSS3
*   **Backend:** PHP
*   **Database:** MySQL
*   **Architecture:** Relational Database Design, RESTful Data Handling
